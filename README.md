# 🩺 MediBot AI

AI-powered medical assistant built with Flask and OpenAI.

## Features

- AI medical chatbot
- Disease information system
- Medicine database
- First aid guide
- Nutrition information
- Medical PDF explanation
- Voice assistant
- User authentication
- Chat history
- Admin dashboard
- RAG based medical search


## Technologies

- Python
- Flask
- SQLite
- OpenAI API
- Sentence Transformers
- HTML
- CSS
- JavaScript
